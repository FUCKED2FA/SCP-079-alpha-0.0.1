尽力了尽力了，只做了两天，压力一个小模型

glitch.py是花屏效果文件，app.py是聊天核心文件，assets是资源文件夹，data是记忆储存

##### 如何使用这个项目：

**1.安装 Ollama 并拉取模型**

**2.安装完成后，打开终端(我使用的VScode），运行以下命令拉取模型：**

ollama run qwen3:8b

**(注：请保持 Ollama 在后台运行，不要关闭。)**

**3. 安装 Python 依赖库**

**打开终端，进入项目根目录，运行以下命令安装必需的库：**

pip install requests Pillow

**4.运行python app.py即可食用**
5.如果想后续继续使用，可能会卡模型，这时候重新在终端输入ollama list刷新一下模型
有小彩蛋，如果你激怒了079，它就会【数据删除】，什么，你还想接着聊？那就把data文件里的json删掉就行

注意：运行后需要点Enter才能开始聊天，这个小模型有很大缺陷，无法完美复刻SCP-079项目。
